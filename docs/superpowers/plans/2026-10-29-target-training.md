# 定点目标训练实施计划

目标：6 拍完成右侧站位的直线/对角后场目标训练，目标由系统事先给出，自动记录输入和落点，支持即时重来。

架构：TargetTraining 独立状态机拥有 ready/flying/result/complete 生命周期；Game 在训练期间委托 step，仍使用原击球求解与物理积分。训练目标只用于提示和事后比较，不传入出球目标。输入记录、提示目标和观察结果使用独立字段，通过 attemptId 关联。正常对战控制映射本轮保持现状，采集数据后再验证候选映射。

- [ ] game/training.js + test/training.test.js：固定左方玩家站位 x=-1.8,z=-4.6；6 拍交替，目标(-1.8,5.25)/(1.8,5.25)，半宽0.75/半深1。悬停喂球，不跑位，无AI/比赛计分。落地或触网后展示4秒，再下一拍。重来追加排除事件并重试同题，不能污染有效样本。
- [ ] game/game.js/net/socket.js/server.js：训练入口权限、断线/接管结束、旧包attemptId拒绝、原始采样字段校验和体积限制、训练状态同步。正常模式和难度切换结束训练后再执行。
- [ ] sens.js/recorder.js：按时间和数量截断的原始motion/orientation环形缓冲；原始数据保留null；记录参考姿态、时间基和识别参数。日志标记prompted目标，不假定用户真实动作与提示必然一致；记录关闭时明确拒绝训练启动。
- [ ] 手机与大屏：可见训练入口、目标高亮、要求和结果区分、重来/退出、完成提示。避免旧球路标注模式抢占。
- [ ] 验证：状态机、边界/触网、重试排除、断线/权限、原始数据截断与落盘，完整回归测试；用真实WebSocket完成训练到落盘的端到端检查，再启动本地服务供试打。

本轮不改变“朝向瞄准/挥拍方向”语义，不把命中目标率描述为意图识别准确率。此功能先提供验证工具和训练数据。
