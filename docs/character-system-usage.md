# 角色系统使用说明

## 在 Blender 编辑当前角色

现有九位角色都使用 `art/characters/roster/<角色 ID>.blend` 的可编辑模型。角色、左右手和选角链接继续使用原来的 ID。经典款、两版棉球、小焰、桃桃、追风、星跃、凌川和晴岚各有自己的模型及选角头像，骨架使用同一套绑定坐标。

在 Blender 4.5 LTS 中编辑并保存模型，先看准备位和击球位的肩肘、髋膝及持拍手，再运行 `npm run characters:build -- <角色 ID>`。省略 ID 会生成全套 GLB 和头像。用 `BLENDER_PATH` 指定 Blender 的程序位置。导出会验证骨骼坐标、轴向、父级和比例，保存的 Blender 文件可以继续手工编辑。当前造型底稿来自 `tools/model-roster.py`，日常导出直接读取已保存的 Blender 文件。

旧版角色开发记录见下文。

已实现：经典运动员、棉球几何版、棉球柔和 GLB 版，手机/大屏选角和权威状态同步，以及可操作的 A/B 对照页。

## 查看与试玩

当前独立预览服务：

- 对照页：http://localhost:3101/characters.html
- 几何版上场：http://localhost:3101/?character=rabbit-geo
- 柔和版上场：http://localhost:3101/?character=rabbit-glb
- 手机控制：与电脑同一网络，扫描预览球场提供的二维码（HTTPS 3544）。

原有 3100 进程未重启，避免中断已有会话。它仍使用原来的服务端代码；查看完整角色系统请使用上面的 3101 预览服务。以后正常重启 `npm start`，角色系统也会运行在默认 3100 / 3543。

对照页支持同步准备/步法/高远球/杀球、左右手、正侧背视角、拖动旋转、暂停与速度调节。A/B 共用动作时间、视角、光照和逻辑击球参数。点击“选 A/B”进入球场，为玩家 1 设置该角色。球场“角色”面板还能为双方分别选角；开场页也可选择。手机进入球场后可选择自己的角色。训练期间禁止换角。

## 两个 Demo 的区别

两套都是本地制作，没有调用付费 AI 图片或 3D 生成服务。它们用同样的设计和肩高、臂展来比较几何部件与蒙皮资产的表现，不是两家 AI 生成工具的成品对比。

- A：低分段、平面着色的独立几何部件，依附骨骼运动。
- B：圆润几何，GLB 内带连续手臂/腿部和混合蒙皮权重；保留原有骨架及基础动作。

为保持现有击球范围，这次保留了原骨架的四肢长度，用大头、宽身体和大鞋表现可爱比例。若进一步缩短四肢，需要重新校准统一的可达范围。表情和耳朵当前为固定形态；羊、熊猫、海绵角色尚未制作。

## 核心文件

- `public/js/characters.js`：前后端共享角色登记表，外部输入只能指定已登记的角色 ID。
- `public/js/character-slot.js`：资源缓存、异步切换、失败回退与旧角色释放。
- `public/js/player.js`：骨架校验、外观选择、材质保留、IK/动画及资源释放。
- `public/js/rabbit-kit.js`：本地兔子造型定义；`models/characters/rabbit.glb` 为导出资产。
- `public/characters.html`、`public/js/character-demo.js`：两套实时 3D 演示。
- `net/socket.js`：`ctrl:character` 仅操作自己拥有的场地；`game:character` 仅已登记大屏可操作双方。

客户端收到权威 `characterId` 后加载角色。双方独立克隆骨架，共享只读源资产。快速切换忽略旧请求；资源或骨架加载失败回退经典运动员，若回退也失败则保留旧角色并显示错误。

## 后续接入 AI 生成模型

遵循 `docs/character-system-research.md` 的设定图提示词：全身 A/T pose，固定主设定后补一致的正侧背图，不在图中拿球拍。用 Tripo/Meshy 生成网格后，离线整理为项目 Mixamo 骨架的命名、绑定姿态、骨轴与身体尺度，再导出 GLB。

本次没有实现任意骨架自动重定向。仅改成相同骨名还不够；请先验证肩/肘/腕/脚以及拍杆方向。耳朵等装饰不要移动 HeadTop_End 高度基准。新模型登记 `appearance: 'imported'`，保留自己的蒙皮和材质。需要队色的材质设置 `material.userData.teamColor = true`，其他颜色不改。

当前加载器支持普通 GLB；Draco/KTX2/Meshopt 压缩资产需另行注册对应解码器。不要直接把未适配模型替换到现有条目里。

## 构建与验证

- `node tools/build-rabbit.mjs`：从现有 Xbot 骨架与本地造型定义重新生成旧版兔子 GLB，无网络依赖。
- `npm test`：74 项通过，包括角色所有权、刷新/重开、错误 ID、加载竞争、回退、资源释放、骨架/权重/动画和两只手触球。
- `npm run test:characters:browser`：需要外部可用的 Playwright、pngjs 与 Chrome，以及正在运行的预览服务；本次使用环境已提供的依赖，未向项目增加运行时依赖。`NODE_PATH` 指向这些包所在目录，可用 `CHARACTER_TEST_URL` 和 `CHROME_PATH` 覆盖地址与浏览器位置。
- 浏览器回归包含 bfcache 返回恢复、暂停前后实际像素姿势保持、高分屏画布稳定性和手机横向溢出。
- 另经真实页面交互验证手机→大屏、大屏→手机选择同步、手机和大屏刷新，以及单人/双人显示；页面未出现 JavaScript 错误。

未完成真机体感及低端设备帧率验收，浏览器检查采用无头 Chrome 软件渲染。柔和版当前约 6.3 万三角形、8 个材质批次，没有移动 LOD；后续根据真机表现再精简。

独立审查发现的返回页资源释放、暂停姿态跳变和高分屏逐帧 resize 问题，均已复现并通过浏览器回归验证修复。基础片段在两个模型加载完成时间不同的情况下可能有微小相位差，挥拍动作时间共享。

## 新增六位搭档（2026-11-03）

画廊入口仍是 `/characters.html`。新增小焰（小恐龙）、桃桃（小猫）、追风（发带少年）、星跃（马尾少女）、凌川（青年运动员）、晴岚（青年运动员）。风格参考分别覆盖0–8、9–17和18–30岁，每组两位；这是推荐风格而非年龄或性别访问限制，任何玩家都可选择。

画廊提供六位角色的实际三维截图、年龄风格筛选、左右预览和直接上场；对照区下拉菜单也保留经典运动员与两版兔子。URL 可使用 `?left=dino&right=kitten` 保存对照组合。六位均为本地几何造型，复用现有骨架与动作，不是六个独立AI生成的蒙皮模型。

新造型集中在 `public/js/roster-kit.js`，默认配色与轮廓相互独立，角色队伍仍由比分和场地标识区分。四肢保持现有可达范围以维持相同玩法。

新增角色验收：99项Node测试通过；六款造型各自完成左右手触球、关节稳定、地面位置与几何预算检查。画廊六角色、三组筛选、预览动作和手机无横向溢出已验证。暂停截图按解码后的像素比较，避免PNG编码差异误报。

## 凌川的 Blender 蒙皮

凌川使用 Blender 制作的运动员网格。手臂、膝、肩和颈部由相邻骨骼共同变形，手指有各自的蒙皮权重。基础骨架沿用项目的 Xbot，继续接收 Court Lab 的反手动作及游戏的跑位和触球计算。进正式球场用 `/?court=backhand` 看反手切吊，也可以从选角列表选择凌川。

凌川现用的源文件为 `art/characters/roster/young-man.blend`。`npm run characters:build:lingchuan` 重新导出该角色的 GLB 和头像。

`art/characters/lingchuan.blend` 是整套角色共用的造型底稿，也是凌川原版模型。
