# COURTSIDE 游戏动线

主入口 `/` 已整合为可玩的俱乐部体验：欢迎首页 → 九角色选择（实时3D预览及试挥）→ 玩法/难度/控制方式 → 比赛 → 真实比分结算/再来一局。角色图鉴 `/characters.html` 作为辅助对照页保留。

视觉采用奶油白、薄荷绿与珊瑚橙。球场为海岸俱乐部风格，有露台、棕榈、阳伞、围栏及标牌；计分、手机连接、队伍与球路反馈沿用服务端状态。手机控制页同步为森林绿与奶油色界面。

## 使用

- 本轮预览入口：http://localhost:3101/；手机扫码使用同局域网 HTTPS3544。
- `npm start` 正常启动为3100/3543，或用 `PORT` / `PORT_HTTPS` 覆盖；所有功能均位于本项目，无外部生成服务或运行时依赖。
- 首页可直接用键盘试玩。单人空格挥拍、A/D调方向；双人另一位用回车与J/L。手机模式按二维码页原有教学完成入场；双人体感需两位手机连接。
- 角色选择先加载预览，再由服务端确认场地角色；就绪后才能进入比赛。快速点击经过短防抖，若请求被拒绝或被另一端覆盖，会在有限等待后恢复与场地一致，避免永远卡在同步。
- 比赛按现有规则先到7分获胜，没有加入领先2分规则。结果面板只显示本轮服务端结束后的实际比分，不填充假战绩。
- 再来一局沿用实际比赛模式，并重新检查网络、角色及手机；条件不足时回准备页。比赛中切换单双人或第二位手机接入会同步到续局模式。
- 返回俱乐部会停止本屏键盘输入，保留角色选择。它不暂停共享服务端对局；下一次进入会开新局。
- 定点训练与原有采集流程保留；训练中不允许随意更换比赛模式和角色。

## 文件

- `public/js/game-flow.js`：可测试的页面、模式、选择确认与结果状态。
- `public/js/game-experience.js`：主入口角色、准备与结果交互。
- `public/js/character-showcase.js`：角色展示场景，进入比赛后停止展示渲染。
- `public/js/coastal-arena.js`：海岸球场与装饰，保留球场/球网及训练对象。
- `public/css/game-experience.css`：首页、选择、准备、球场HUD和赛后界面。
- `test/game-flow.test.js`：就绪门槛、结果、模式续接、被覆盖选角的回归。
- `test/browser/game-experience.cjs`：桌面/手机完整动线与快速选角回归。通过现有环境的Playwright执行；可配置 `CHROME_PATH`、`CHARACTER_TEST_URL`，`NODE_PATH` 指向浏览器工具包目录。

没有改动核心球路、命中半径、AI或计分规则。本轮没有发布到互联网；对外联机仍需后续部署与有效HTTPS域名。浏览器验证使用软件渲染，低端真机体感和性能仍需现场验收。

本轮最终验证：105项Node测试通过。浏览器实际跑通完整主流程及角色快速切换；实际键盘对局以7:6结束，结果面板与服务端一致，再来一局归零。独立审查发现的模式续接、续局就绪和待确认角色锁定问题均已复现并通过回归修复。发球阶段持续显示轮次与操作提示。低端真机和公网多房间不在本轮交付范围。
