# 项目总览

## 1. 项目定位

局域网 3D 体感羽毛球。大屏负责渲染球场和两名角色，手机作为体感球拍：

- 单人模式：玩家对战电脑
- 双人模式：两台手机左右分屏对战
- 手机通过陀螺仪/加速度计控制球拍方向、挥拍力度与球路

## 2. 快速开始

```bash
npm install
npm start
```

| 入口 | 地址 |
| --- | --- |
| 大屏游戏 | `http://<局域网IP>:3100/` |
| 手机手柄 | `https://<局域网IP>:3543/ctrl` |
| 服务统计 | `http://<局域网IP>:3100/api/stats` |

手机端使用传感器必须走 HTTPS（自签证书），首次打开需信任证书。

## 3. 技术栈

- Node.js + Socket.IO，服务端权威判定
- 原生 HTTP/HTTPS 静态服务，无构建步骤
- Three.js（浏览器 ES Module）渲染，GLB 骨骼模型
- 大屏、手机端均为单页 HTML + 内联 JS

## 4. 代码结构

```text
server.js                 对局状态机、AI、球路物理、Socket 事件
public/index.html         大屏：3D 场景、HUD、分屏相机、音效
public/ctrl.html          手机端：传感器、校准、挥拍判定、UI
public/js/player.js       GLB 人物视图、手臂/腿部 IK、球拍挂载
recorder.js               手机体感数据采集（JSONL）
data/                     sessions 原始采集、labels 人工标注、tools 汇总脚本
models/Xbot.glb           球员骨骼模型（Mixamo）
.doc/                     本规范目录
```

## 6. 已知限制

- 浏览器无法读取音量键，姿态重置只能使用屏幕按钮。
- iPhone Safari 不支持网页全屏，可“添加到主屏幕”使用。
- “息屏”是黑色遮罩锁触，无法真正关闭物理屏幕。
- `models/Xbot.glb` 来自 Mixamo，对外分发前需确认授权范围。
