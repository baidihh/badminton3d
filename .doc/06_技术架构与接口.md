# 技术架构与接口

## 1. 总体结构

```text
手机 ctrl.html ──Socket.IO──▶ server.js ──state(60Hz)──▶ 大屏 index.html
   传感器/校准/挥拍判定          权威状态机/物理/AI         Three.js 渲染/相机/HUD
                                      │
                            /vendor /addons /models 静态资源
```

服务端不保存历史，只维护当前对局状态；所有击球、得分以服务端判定为准。

## 2. 模块职责

服务端按"入口 / 规则 / 物理 / 网络"分层，前端按"页面 / 子系统"拆分，单文件不再混杂多类职责。

| 文件 | 职责 |
| --- | --- |
| `server.js` | 入口：HTTP/HTTPS、静态资源、API、Socket 装配、主循环 |
| `game/constants.js` | 世界常量、`clamp/moveTo/rand`、球路集合、AI 难度表 |
| `game/physics.js` | 二次阻力积分、弹道模拟、初速度反解、扫掠几何（纯函数） |
| `game/game.js` | 对局状态机：发球、击球判定、跑位、AI、计分、快照 |
| `net/socket.js` | Socket.IO：场地分配、手柄输入、延迟测量、断线回收 |
| `recorder.js` | 体感数据采集：按手柄会话写 JSONL，姿态 20 Hz 采样 |
| `public/index.html` | 大屏结构（仅 DOM） |
| `public/css/screen.css` | 大屏样式 |
| `public/js/screen.js` | 大屏渲染：球场、角色、球与特效、HUD、相机、主循环 |
| `public/js/player.js` | GLB 克隆、骨骼查找、手臂/腿部 IK、球拍挂载、球路朝向 |
| `public/ctrl.html` | 手机端结构（仅 DOM） |
| `public/css/ctrl.css` | 手机端样式 |
| `public/js/ctrl/main.js` | 手机主流程：按键、校准、试挥、联机、UI、渲染循环 |
| `public/js/ctrl/sens.js` | 传感器与挥拍识别：姿态解算、滤波、挥拍窗口、球路分类 |
| `public/js/ctrl/mirror.js` | 3D 姿态镜（手机 + 球拍） |
| `public/js/ctrl/radar.js` | 前半球落点雷达 |
| `public/js/ctrl/audio.js` | 挥拍音效（WebAudio 合成） |
| `public/js/ctrl/util.js` | 前端通用常量与数学工具 |
| `public/js/ctrl/gate.js` | 挥拍节流状态（传感器与出球共用） |

依赖方向：`main → sens/mirror/radar/audio → util`，`sens` 不反向依赖 `main`；
出球动作通过 `setSwingHandler(fire)` 注入，避免循环引用。

## 3. 运行与端口

- `node server.js` 同时启动 HTTP 3100 与 HTTPS 3543。
- HTTPS 证书读取 `certs/key.pem`、`certs/cert.pem`；证书缺失时自动生成自签证书。
- 静态映射：
  - `/vendor/` → `node_modules/three/build`
  - `/addons/` → `node_modules/three/examples/jsm`
  - `/models/` → `models/`
- 页面与 JS 使用 `Cache-Control: no-store`，模型与 three 资源缓存 1 小时。

## 4. 对局循环

- 固定步长 60 Hz 累积推进（`TICK = 1/60`）。
- 每步：自动跑位 → 抬拍 → AI 决策 → 击球判定 → 球体积分 → 触网/落地判定。
- 每个 tick 广播一次 `state`，客户端用外推 + 插值平滑球与角色。

## 5. Socket 事件

### 手机/大屏 → 服务端

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `ctrl:join` | `{slot?, name?, hand?}` | 申请场地，可指定左/右与持拍手 |
| `ctrl:hand` | `{hand}` | 运行时切换持拍手 |
| `ctrl:motion` | `{rate, events}` | 传感器速率统计 |
| `ctrl:pose` | `{q:[x,y,z,w], az, el, om, hand}` | 真实手机姿态（30 Hz），服务端按 20 Hz 采样落盘 |
| `ctrl:swing` | `{power, dir, peak, lift, shot, az, azRaw, ageMs, rttMs}` | 手机挥拍；`az` 为中值滤波后的方位角，`azRaw` 为峰值单帧原始值，`ageMs` 为峰值到发包的延迟，`rttMs` 为实测往返延迟 |
| `ctrl:ping` | `{t}` | 延迟测量，服务端立刻回 `ctrl:pong` |
| `game:swing` | `{side, power, dir, lift, shot}` | 大屏键盘挥拍 |
| `game:restart` | — | 重开 |
| `game:mode` | `{ai}` | 单人/双人 |
| `game:difficulty` | `{level}` | `easy` / `normal` / `hard` |

### 服务端 → 客户端

| 事件 | 参数 | 说明 |
| --- | --- | --- |
| `state` | 快照 | 球、双方、阶段、比分、击球特效 |
| `ctrl:joined` | `{slot}` | 分配结果 |
| `ctrl:full` | — | 场地已满 |
| `ctrl:released` | — | 被其他设备接管 |
| `ctrl:hit` | `{grade, power, shot}` | 命中反馈 |
| `ctrl:miss` | `{reason}` | 漏击反馈：`far` / `high` / `late` / `early` |
| `ctrl:pong` | `{t, now}` | 延迟测量回包（`now` 为服务端模拟时钟） |
| `mode:set` | `{twoPlayer}` | 自动切换分屏 |

### 状态快照字段

- `ball`: `x, y, z, vx, vy, vz`
- `left` / `right`: `x, y, z, score, dir, connected, flash, name, ai, hand, pose, grade, vx, vz`
- `phase`: `serve | rally | point | over`
- `server`、`started`、`msg`、`rally`、`impact`、`winScore`

## 6. HTTP 接口

| 路径 | 说明 |
| --- | --- |
| `/api/stats` | 比分、阶段、位置、手柄统计 |
| `/api/rec` | 采集状态；`?on=0` / `?on=1` 关闭或开启 |
| `/api/net` | 局域网地址与端口 |
| `/api/qr?text=` | 生成 SVG 二维码 |

## 7. 客户端渲染管线（每帧）

1. 动画混合（idle/walk/run）。
2. 躯干跟随球与手机机头扭转。
3. 头部追球。
4. 腿部 IK：世界坐标落脚点、步态、弓步、重心下沉。
5. 持拍手 IK：手机姿态 → 肩部限位 → 肘/腕 → 球拍朝向。
6. 球拍发光、软影、特效与相机更新。
