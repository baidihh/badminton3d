# 羽毛球技术动作与实现映射

## 1. 目的

把真实羽毛球的技术动作系统梳理一遍，对照当前项目已经能做的、能做但没做的、做不了的，形成后续开发优先级与判定规则草案。

原则：**先保证手机上能稳定打出来，再追求动作数量**；每个新动作都要有明确的判定信号、物理落点和可读反馈。

## 2. 技术动作全景

真实羽毛球按击球区域分为四类，另有发球与步法两套独立体系。

### 2.1 后场（底线附近）

| 动作 | 真实特征 | 战术用途 |
| --- | --- | --- |
| 高远球 | 高弧线到底线，飞行时间长 | 拉开对手、争取回中时间 |
| 平高球 | 弧线较低但过顶，速度快 | 压制后场、限制对手下压 |
| 吊球 | 后场轻击到网前两角 | 调动前后、破坏站位 |
| 劈吊 | 斜拍面切削，落点更贴网 | 制造假动作、突然性强 |
| 杀球 | 高点全力下压，速度最快 | 直接得分、迫使起高 |
| 点杀 | 手腕小幅度快速下压 | 突然、省力、落点前 |
| 反手高远/吊/杀 | 背身反手，力量弱但出球突然 | 被动解围 |

### 2.2 中场（平抽快挡区）

| 动作 | 真实特征 | 战术用途 |
| --- | --- | --- |
| 平抽 | 拍面与地面近乎平行，平快过网 | 双打主战手段、抢节奏 |
| 推球 | 网前或中场平推两底线 | 压后场、打空当 |
| 接杀挡网 | 借力挡到网前 | 化解杀球、转守为攻 |

### 2.3 前场 / 网前

| 动作 | 真实特征 | 战术用途 |
| --- | --- | --- |
| 搓球（放网） | 拍面轻托，球贴网翻滚 | 逼对手挑球 |
| 勾对角 | 手腕外旋，斜线过网 | 打乱直线站位 |
| 挑球 | 低点向上高挑到底线 | 被动过渡、争取时间 |
| 扑球 | 网前高点快速下压 | 直接得分 |

### 2.4 发球

| 发球 | 真实特征 | 战术用途 |
| --- | --- | --- |
| 高远球 | 高弧线到底线 | 单打常用、限制进攻 |
| 平高球 | 弧线低、速度快 | 突然性强 |
| 平快球 | 贴网平飞 | 偷袭后场 |
| 网前球（短球） | 刚好过网 | 双打、限制扑球 |

### 2.5 步法

| 步法 | 真实特征 | 当前项目 |
| --- | --- | --- |
| 并步 | 小步幅横向移动 | 已覆盖（横移落脚） |
| 交叉步 | 大步幅、后脚交叉 | 已覆盖（大横移时非持拍脚交叉到身后） |
| 垫步（启动步） | 对方击球瞬间小跳蓄力 | 已覆盖（球进入本方半场的瞬间小跳） |
| 跨步 / 弓步 | 前场大跨、重心下沉 | 已覆盖 |
| 蹬转步 | 后场侧身、蹬地转体 | 部分覆盖（躯干扭转） |
| 回中 | 击球后回中心位 | 服务端 `autoFootwork` 负责回中 |

## 3. 我们能用手机观测到什么

判定只能依赖这些信号，任何新动作都必须能落到其中几项的组合：

| 信号 | 来源 | 已有用途 |
| --- | --- | --- |
| 仰角峰值 `elMax` / 起始 `elStart` / 最低 `elMin` | 前后半球投影 | 区分高远与杀球 |
| 方位 `az` / 横向扫角 `peakSweep` | 前半球投影 | 落点左右、方向 |
| 峰值角速度 `peak` | 陀螺仪 | 力度、快慢 |
| 挥拍时长 | 起拍到回落 | 幅度大小 |
| 按住吊球键 | 屏幕修饰键 | 吊球 |
| 持拍手 | 设置 | 左手镜像 |
| 触球高度 `b.y` | 服务端 | 杀球降级、可及范围 |
| 击球时机 | 球与拍心距离 | 甜区、漏击原因 |
| 拍面法线 | 手机姿态 | 目前仅视觉，可用于切削类判定 |

限制：**无法感知握拍方式、手腕内旋、拍面细节角度**，所以“搓球/勾对角”这类高度依赖手腕的动作只能做近似。

## 4. 真实动作 → 项目映射

| 真实动作 | 可近似为 | 判定信号 | 现状 |
| --- | --- | --- | --- |
| 高远球 | ✅ 已实现 | 仰角上升 > 8.6°，仰角峰值 < 22° | 可用 |
| 平高球 | ⚠️ 可合并进高远 | 同高远但飞行时间更短、弧线更低 | 未做 |
| 吊球 | ✅ 已实现 | 按住修饰键 | 可用，最稳 |
| 劈吊 | ✅ 可做 | 高点击球 + 大方位扫角 + 中低力量 | 未做 |
| 杀球 | ✅ 已实现 | 仰角峰值 > 22° + 速度 | 可用 |
| 点杀 | ✅ 可做 | 仰角峰值 > 22° + 扫角小 + 时长 < 0.25 s | 未做 |
| 平抽 | ✅ 可做 | 仰角接近水平（-6°~+8°）+ 大扫角 + 速度快 | 未做 |
| 推球 | ✅ 可做 | 仰角略上 + 中等力量 + 大方位 | 未做 |
| 搓球（放网） | ⚠️ 近似 | 低触球点 + 极小力量 + 小幅前送 | 未做 |

## 5. 优先级与规则草案

### P0（已完成，继续微调）

- 高远、吊球、杀球、发球、漏击原因、步法（并步/跨步/弓步）。

### P1（建议下一版做，性价比最高）

**1）平抽 `drive`**

- 手势：拍头在网高附近横向快扫，仰角基本水平。
- 规则：`-0.12 < elMax < 0.14` 且 `|sweepDeg| > 45` 且 `peak > 520`。
- 物理：目标深度 3.4–5.2 m，飞行时间 0.55–0.7 s，过网高度目标 1.7–1.9 m（贴网）。
- 反馈：`#9AD9FF` 冷青，音效短促、顿帧 0.03 s。

**2）挑球 `lift`**

- 手势：低点（触球高度 < 1.5 m）向上挑，弧度大。
- 规则：`b.y < 1.5` 且 `elMax - elStart > 0.25` 且 `peak` 中速。
- 物理：目标深度 5.2–6.2 m，飞行时间 2.0–2.3 s，高弧线。
- 反馈：与高远同色但更暗，提示“挑起来了”。

**3）推球 `push`**

- 手势：中等幅度平推，方位明显偏边线。
- 规则：`|sweepDeg| > 30` 且 `elMax < 0.2` 且 `peak` 中速。
- 物理：目标深度 4.0–5.5 m，飞行时间 1.0–1.2 s，落点靠边线。

### P2（有手感风险，先做实验）

**4）搓球 / 放网 `net`**

- 前提：触球点很低（< 1.1 m）、离网近。
- 规则：极小力量（power < 0.18）+ 小幅前送 + 按住吊球键（复用修饰）。
- 风险：手机难感知“轻”，容易变成下网；需要服务端做过网保护与失败反馈。

**5）劈吊 `cut`**

- 规则：高点击球 + 仰角高 + 方位扫角大 + 力量中低。
- 物理：落点前场边线，飞行时间 1.2–1.4 s。

**6）点杀 `punch`**

- 规则：杀球条件 + 挥拍时长 < 0.25 s + 扫角 < 25°，力量中等。
- 物理：落点 2.6–3.4 m，飞行时间 0.75 s。

## 7. 判定冲突与顺序

推荐固定判定顺序，避免多个条件互相抢占：

1. 按住吊球 → `drop`（若力量极小且低点 → `net`）
2. 仰角峰值 > 22° → `smash`（扫角小时 → `punch`）
3. 仰角接近水平且大扫角快速 → `drive`
4. 低点大幅向上 → `lift`
5. 仰角上升 → `clear`（速度高且弧线低时 → `fast_clear`）
6. 其余 → `clear`

同一招不能既算平抽又算高远，顺序即优先级。

## 8. 步法对照与改进

程序化步法已覆盖并步、跨步、弓步与重心下沉，本轮补齐两块（`public/js/player.js`）：

| 步法 | 真实表现 | 实现 |
| --- | --- | --- |
| 启动步 | 对方击球瞬间小跳蓄力，双脚离地一拍 + 站位加宽 | 球刚进入本方半场（`onMy` 上升沿）触发 0.16 s 小跳，`splitK` 正弦包络同时抬脚 5 cm、两脚外扩 5 cm；0.8 s 冷却避免连续触发 |
| 交叉步 | 大范围横移时后脚从身后交叉 | 横移分量 `|mlx| > 0.55` 且明显大于前后分量时：非持拍脚外摆 0.60 并向后退 0.18（从身后交叉），持拍脚只跟 0.10 |
| 回中 | 击球后回中心 | 由服务端 `autoFootwork` 负责（球不在本方半场时回 `PLAYER_Z`，横向归零） |

局限：人物是单刚体根节点 + 两段腿 IK，没有真正的重心位移，交叉步是"脚的位置交叉"而非全身转体；后续若要更像，需要给根节点加身体朝向扭转与重心平移。

## 9. 教学与反馈

- 手机端每个球路配一句可执行提示：高远“从下往上送”、平抽“拍面放平横着扫”、挑球“低点往上挑”。
- 大屏计分板标签扩展到新球路（平抽/挑球/推球），颜色区分。
- 练习模式从 3 种扩展到“3 必学 + 2 进阶”，先高远/吊/杀，通过后再解锁平抽/挑球。

## 10. 验证方案

- 标注模式扩展为 5–6 种球路，每种 4 拍，共 20–24 拍。
- 指标：各球路混淆矩阵、误判率、漏击率、平均命中高度。
- 验收标准：新球路判定一致率 ≥ 80%，且不劣化高远/吊球/杀球的现有准确率。

## 11. 取舍说明

- 不做反手：手机无法识别握拍方向，强行做会让判定更乱。
- 不追求一次上 10 种动作：手机体感的可分辨维度有限，动作越多越容易互相误判。
- 优先做“轨迹差异大、判定信号清晰”的动作（平抽、挑球），暂缓“依赖手腕细节”的动作（搓球、勾对角）。
