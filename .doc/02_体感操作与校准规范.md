# 体感操作与校准规范

## 1. 传感器与权限

- 使用 `DeviceOrientationEvent`（alpha/beta/gamma）与 `DeviceMotionEvent`（`rotationRate`、`accelerationIncludingGravity`）。
- iOS 13+ 需用户手势触发权限申请，且页面必须是 HTTPS。
- 原始陀螺仪缺失时自动降级为融合姿态/挥动幅度判定。

## 2. 两步校准

| 步骤 | 规则 |
| --- | --- |
| 1. 静止采样 | 2 秒内采集加速度与陀螺仪，计算噪声、陀螺零偏与触发阈值 |
| 2. 确定初始姿态 | 记录当前手机姿态为基准，按钮为「确定初始姿态」 |

- 陀螺零偏取中位数；零偏模长 > 45°/s 视为转动中，不扣偏置并降级融合姿态。
- 弹窗/球路练习前必须先完成校准，否则不允许发球。

## 3. 姿态映射（真实拍位）

- 手机机头（设备 +Y）即拍杆方向，屏幕法线（设备 +Z）即拍面法线。
- 校准保留**手机真实仰角**：`qBase = Rx(90° - el0)`，`el0` 为校准时手机机头在世界坐标的仰角。
- 初始方位角统一为身前正前方；手机放平 → 拍子低，手机抬高 → 拍子高，避免拍子永远举着。
- 目标方向越过后半球时，压到前半球最大圆平面（z = 0），避免手臂绕到身体后方。
- 大屏手臂另有硬限位：肩部水平 ±95°、仰角 -34°～77°。

## 4. 挥拍识别

- 主判定：原始陀螺仪角速度峰值超过阈值（阈值随静止噪声自适应）。
- 起拍：角速度超过阈值后进入挥拍窗口，必须回落至阈值 50% 以下才允许下一次挥拍（迟滞）。
- 力度取单次挥拍最大单向扫角，收拍不会抵消。
- **出球方向取出球瞬间的方位角**：记录角速度峰值那一刻的 `az`（`azAtPeak`）并上传，而不是收拍后的方位——收拍阶段球拍已跨到身体另一侧，用它算落点会把直线球判成对角球。
- 方位角约定：`+` = 玩家自己的右侧；服务端按半场换成世界 x（左半场 × -1），所以左右手、左右半场的动作都能镜像。
- 球路分类见 `03_球路与物理判定.md`。

### 4.1 滤波

参考 NERD 为 Switch Sports 做的传感器滤波，判定链路上加了三处：

| 环节 | 方法 | 参数 | 目的 |
| --- | --- | --- | --- |
| 角速度触发 / 峰值 | 3 点中值 | 最近 3 帧 | 去掉单帧尖峰误触发；真实挥拍峰值保留约 95% |
| 仰角峰值 / 谷值 | 3 点中值 | 最近 3 帧 | 单帧跳动不会把高远球误判成杀球 |
| 出球方向 | 峰值 ±60 ms 窗口的方位角中值 | 至少 3 个样本，否则回退到峰值单帧值 | 手抖或单帧跳变不会改变落点 |
| 雷达显示 | 自适应一阶低通 | 静止 α≈0.30，快速挥拍 α≈0.95 | 视觉平滑且不牺牲跟手，不参与判定 |

- 判定和出球都用滤波后的值；原始值 `azRaw` 一并上报落盘，方便对比滤波前后的差异。
- 滤波只处理单帧毛刺，不改变真实的持续峰值，所以力度和球路阈值的标定基本不受影响。

## 5. 持拍手与按钮布局

- 手机端可切「右手持拍 / 左手持拍」，同步给大屏角色（左右手臂骨轴镜像、球拍换手）。
- 吊球键按持拍手放在屏幕左侧或右侧，用拇指按住。
- 吊球键尺寸 154×52 px，字号 14，最低高度 52 px。

## 6. 姿态重置

- 按钮位于屏幕中上部（3D 镜下方），尺寸与吊球键一致。
- **单击立即生效**：以当前手机姿态为新基准，马上修正异常姿态；无长按确认。
- 按下仅 0.16 秒高亮反馈，不参与判定。

## 7. 全屏与息屏

- 全屏：`requestFullscreen`，兼容 `webkitRequestFullscreen`；iPhone Safari 不支持时给出提示，可“添加到主屏幕”。
- 息屏：纯黑遮罩拦截全部触摸，避免误触；长按 0.65 秒唤醒。
- 息屏期间传感器与挥拍照常工作，并使用 Wake Lock 保持页面活跃。
- 浏览器无法真正关闭物理屏幕，也无法捕获音量键。

## 8. 手机端辅助界面

- 3D 姿态镜：手机模型实时跟随真实姿态（最大显示倾角 60°）。
- 落点雷达：显示方位/仰角与前半球限位提示。
- 指定球路练习：随机给出高远/吊/杀各一次，同时判定球路与时机。
- 命中反馈：文字按球路着色，配合振动与音效。
