# 玩法与计分规范

## 1. 场地与球网

| 参数 | 数值 |
| --- | --- |
| 半场宽（x） | 3.0 m |
| 半场长（z） | 6.7 m |
| 球网高度 | 1.55 m |
| 球网半宽 | 3.1 m |
| 左右活动边界 | ±2.9 m |
| 玩家初始纵深 | ±4.6 m |
| 球拍可及半径 | 0.98 m |

## 2. 对战模式

- 单人：玩家 1 对电脑，电脑默认占据右侧场地。
- 双人：两台手机分别接入左/右场地，大屏切分为两个过肩视角。
- 手机可通过「切换场地」改变自己的半场；第二台手机接入右侧时自动切双人。

## 3. 发球规则

1. 每回合结束由得分方发球。
2. 发球阶段球固定在发球点上方 2.5 m，不再自己掉落，等发球方挥拍击出。
3. 玩家发球：看手机提示「挥拍」，击球即开始回合。
4. 电脑发球：电脑拿到发球权后 0.5–1.1 秒内主动挥拍；超过 3.5 秒仍未击出则强制发球，避免卡死。
5. 发球必须过网，否则按触网处理，重新发球。

## 4. 回合判定

| 情况 | 判定 |
| --- | --- |
| 球落地 | 落在哪一侧，对面得分 |
| 击球触网（未过网） | 击球方失分 |
| 未在有效窗口挥拍 | 漏击，球继续飞行，最终按落地结算 |

- 每名玩家同时只保留一次待判定挥拍，挥拍窗口 0.3 秒。
- 击球判定条件：球在己方半场、球与拍面中心距离 ≤ 0.98 m。

## 5. 计分与胜负

- 每球一分，先到 7 分获胜。
- 得分、触网、落地会在大屏顶部计分板与提示条显示。
- 一局结束后可点「重开」重置比分与发球权。

## 6. 跑位

- 当前由服务端自动跑位：预判球的落点，站到球后侧约 0.55 m。
- 球不在己方半场时回到中场，移动带加速与场地边界限制。
- 大屏角色步法由客户端 IK 程序化生成，见 `02_体感操作与校准规范.md`。
