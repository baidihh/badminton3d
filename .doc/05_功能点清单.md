# 功能点清单

## 1. 大屏（`public/index.html`）

- GLB 骨骼角色、球拍、球场、灯光、软阴影、过肩跟随相机。
- 单人全屏 / 双人左右分屏，自动切换。
- 球路视觉编码：拖尾、光晕、火花、冲击波、闪光颜色。
- 计分板、球路标签（高远/吊球/杀球）、击球评分（完美/好球/擦边）。
- 音效：击球三档音色、得分音、触网音；震屏与顿帧。
- 开球提示、发球方提示、手机连接状态、手机姿态小卡。
- 电脑难度选择（开始页与底部栏），双人模式自动隐藏。
- 手机连接二维码、重开、声音开关。
- 键盘试玩：空格挥拍、A/D 调整落点。

## 2. 手机端（`public/ctrl.html`）

- 体感权限申请、2 秒静止校准、初始姿态确认。
- 真实手机姿态映射：机头指哪拍子指哪，保留校准仰角。
- 前半球投影与肩部硬限位，手臂不会绕到身后。
- 3D 姿态镜、落点雷达、超出范围提示。
- 挥拍识别：陀螺仪优先，融合姿态兜底；力度、方向、球路。
- 三种球路：向上高远、按住吊球、举高下压杀球。
- 指定球路练习（三种各一次，判定球路 + 时机）。
- 命中/漏击反馈：文字、颜色、振动、音效。
- 持拍手切换（右手/左手），按键随持拍手换边，大屏人物同步换手。
- 姿态重置：中上部大按钮，单击立即生效。
- 全屏、息屏防误触（长按 0.65 秒唤醒）、屏幕常亮。
- 切换场地、左右打反修正、重新教学。

## 3. 服务端（`server.js`）

- 60 Hz 权威对局状态机：发球、回合、得分、结束。
- 球路物理：高远/吊/杀、过网保护、触球高度影响、低点杀球降级。
- AI：三档难度、发球计划、失误、压空当、卡死兜底。
- 场地分配：自动分配、同 IP 接管、8 秒无数据回收。
- HTTPS 手机页、二维码、统计接口、静态资源映射。

## 4. 已知限制

- 音量键无法被网页捕获，重置只能点屏幕按钮。
- iPhone Safari 不支持网页全屏。
- 息屏为黑色遮罩锁触，非物理熄屏。
- 手机传感器要求 HTTPS，自签证书首次需手动信任。
- 后半球动作被投影压平，极端姿态下拍面与手机法线存在角度差。
